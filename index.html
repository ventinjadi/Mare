Preferências e sincronização

O Maré exige login antes de acessar os registros. Sua conta pode ser sincronizada pelo Supabase.

Use somente a chave pública/anon. Nunca cole a chave service_role ou secret aqui.

Antes de conectar, execute o arquivo supabase.sql no SQL Editor do seu projeto. A tabela possui políticas de acesso por usuário (RLS).

Entrar ou criar conta

Os dados locais permanecem neste navegador até serem apagados pelo usuário ou pelo próprio navegador. Sem uma conta conectada, eles não são sincronizados entre dispositivos. Faça backups periódicos.
